# Configuration Files

Backups of configuration files for machines, devices, and software I use, so they can be
restored quickly after a wipe, reinstall, or hardware swap.

Every folder follows a common [README template](docs/README_TEMPLATE.md) describing
what's backed up, where it belongs on the real system, and how to restore it.

## Structure

- [`hardware/devices`](hardware/devices/README.md) — general-purpose devices (tablets, handhelds).
- [`hardware/machines`](hardware/machines/README.md) — single-purpose machines (3D printers, CNCs, laser engravers).
- [`software`](software/README.md) — desktop software configuration/presets.

See [`docs/README_TEMPLATE.md`](docs/README_TEMPLATE.md) for the documentation standard
used across the repository.
